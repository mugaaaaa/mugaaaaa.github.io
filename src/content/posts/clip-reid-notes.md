# 一段话总结
本文是将预训练的视觉语言模型 CLIP 应用到 ReID 的下游任务的微调工作。具体方法是为每一个 ID 提供一个可学习的文本标记(`CLS`)，并将它们提供给文本编码器以形成模糊描述，然后采用两阶段训练：
- 第一阶段：冻结 CLIP 的文本编码器和图像编码器，学习文本标记（`CLS`）
- 第二阶段：冻结文本标记和他的编码器，微调 CLIP 图像编码器

# 背景及相关工作简述
## 背景
1. Image re-identification (ReID)：
   1. 旨在在不同且不重叠的摄像机视图中匹配同一对象
   2. 主要挑战：杂乱的背景、照明变化、巨大的姿势变化，甚至遮挡等
   3. 这之前的 ReID 方法大多基于 CNN
   4. 基于 CNN 和基于 ViT 的方法都严重依赖预训练，而 ReID 的数据集相对较小，几乎所有 ReID 方要一个在 ImageNet 上训练的初始模型。
## 相关工作
1. CLIP: 
   1. 采用双塔结构，包含一个图像编码器（如 ViT 或 ResNet）和一个文本编码器（Transformer），将视觉信息和自然语言描述映射到了同一个连续的特征空间中
   2. 基于从互联网收集的 4 亿对海量“图像-文本”数据对进行预训练。模型通过对比学习，不断拉近匹配的图文对（正样本）在特征空间中的距离，同时推远不匹配的图文对（负样本）
   3. 具备强大的零样本（Zero-shot）泛化能力和极其丰富的开放世界语义常识
      1. 由于经过了跨模态对齐，CLIP 提取的视觉特征不再只是单纯的像素级特征，而是融合了高级语义属性（例如“红衬衫”、“双肩包”）。这种包含语义的特征对 ReID 任务中常见的杂乱背景、光照变化和视角遮挡具有极强的天然鲁棒性。
2. Context Optimization(CoOp):
   1. 是将 CLIP 等视觉-语言大模型适配到具体下游任务时，最经典且最具开创性的一种 **提示学习（Prompt Learning）** 方法。
   2. 在 CoOp 出现之前，让 CLIP 做分类或识别，必须人工写提示词，比如 "A photo of a [CLASS]"
   3. CoOp 抛弃了英文字母，直接在特征维度上做文章。
   它将输入文本编码器的前缀变成了一组可学习的数学向量，结构变成了：
   ```
   [V1] [V2] [V3] ... [CLASS]。
   ```
   [CLASS] 依然是特定类别或具体 ID 的词向量。
   `[V1]~[Vn]` 是随机初始化的、没有具体人类语言含义的“虚拟单词”（也就是连续向量）。
   4. 训练过程：在微调阶段（相当于 CLIP-ReID 的两第一阶段）：
      1. 冻结 CLIP 的文本编码器和图像编码器（不改变其预训练的常识）。
      2. 根据特定任务的损失函数（Loss），利用反向传播只更新那几个 `[V]` 向量的参数。
   5. 效果：经过优化，连续提示向量 [V] 能够收敛为高度契合目标任务的语义先验，从而高效引导 CLIP 提取精准的视觉特征

# 创新点
1. 冲突：CLIP 需要吃“句子”，但数据集只有“ID=001” 等标签
2. 解决方案：
   1. 使用一串可学习的代码 `[V1][V2]...[ID_001]` 来代替句子
   2. 训练方法：
      1. Stage 1（造句子阶段）： 冻结大模型。只训练 [V] 向量，让这些伪造的文本特征在空间中努力向真实的图像特征靠拢（图1第一阶段）。
      2. Stage 2（图像认祖归宗阶段）： 冻结造好的“句子”。放开图像编码器进行微调，利用跨模态损失，强迫同一个人的所有图片特征，都向刚才造好的那个文本特征聚拢，从而拉开不同人之间的距离。

## CLIP-ReID（这里基本照搬原文）
这篇文章的模型通过预训练一组可学习的文本标记来补充缺失的文本信息。如图所示，他们的方案建立在经过两阶段训练的预训练 CLIP 之上
### 第一阶段训练
- 首先引入特定于 ID 的可学习标记来学习模糊的文本描述，这些描述对每个 ID 是独立的：输入到 $\mathcal{T}(\cdot)$ 的文本描述被设计为
> “A photo of a `[X]`$_1$`[X]`$_2$`[X]`$_3$...`[X]`$_M$ person/vehicle”

，其中每个 `[X]`$_m (m \in 1, ...M)$ 都是一个与词嵌入维度相同的可学习文本标记。$M$ 表示可学习文本标记的数量。

- 在这个阶段，我们固定 $\mathcal{I}(\cdot)$ 和 $\mathcal{T}(\cdot)$ 的参数，只优化标记 `[X]`$_m$。与 CLIP 类似，我们使用 $\mathcal{L}_{i2t}$ 和 $\mathcal{L}_{t2i}$，但在公式 (1) 中将 $text_i$ 替换为 $text_{y_i}$，因为同一个 ID 共享相同的文本描述。
- 此外，对于 $\mathcal{L}_{t2i}$，批次中不同的图像可能属于同一个人，因此 $T_{y_i}$ 可能有多个正样本，我们将其修改为：
$$
\mathcal{L}_{t2i}(y_i) = -\frac{1}{|P(y_i)|} \sum_{p \in P(y_i)} \log \frac{\exp(s(V_p, T_{y_i}))}{\sum_{a=1}^B \exp(s(V_a, T_{y_i}))} \quad (4)
$$

>  - 公式解析：这个公式计算的是：给定一个身份（ID）的文本，它找对属于自己所有照片的损失。
>    - $y_i$： 当前正在处理的身份 ID（例如：ID=001，张三）。
>    - $T_{y_i}$： 张三的文本特征。这是由第一阶段那些可学习的标记 [X1][X2]...[张三ID] 输入到文本编码器后生成的向量。
>    - $P(y_i)$： 正样本集合（Positive Set）。 这是一个集合，里面装了当前批次（Batch）中所有属于张三的图片的编号。比如当前批次有 64 张图，第 2、5、8 张是张三，那么 $P(y_i) = \{2, 5, 8\}$。
>    - $|P(y_i)|$： 集合里元素的数量，也就是正样本的个数（在刚才的例子里，数量是 3）。
>    - $V_p$： 集合里某一张正确的张三图片的视觉特征。
>    - $V_a$： 批次里的任意一张图片的视觉特征（从第 1 张到第 $B$ 张，不论是谁的）。$s(\cdot, \cdot)$： 计算两个特征向量的余弦相似度（得分越高越相似）。
>   - 结构：
>     - 分数部分（Softmax 概率）：$$\frac{\exp(s(V_p, T_{y_i}))}{\sum_{a=1}^B \exp(s(V_a, T_{y_i}))}$$这其实是一个概率值。分母是“张三文本”和批次里所有图片的相似度之和；分子是“张三文本”和某一张正确的张三图片 $V_p$ 的相似度。大白话理解： 把张三的文本描述丢进这一堆照片里，模型能精准识别出 $V_p$ 这张照片就是张三的概率有多大。
>     - $-\log$（交叉熵损失）：概率越接近 1（找得越准），$-\log$ 的值就越接近 0（损失越小）；找得越不准，损失就越大。
>     - $\sum_{p \in P(y_i)}$（求和）：因为张三不止一张照片（有 $V_2, V_5, V_8$），所以我们要把找这 3 张照片的损失全部加起来。
>     - $\frac{1}{|P(y_i)|}$（求平均）：为什么要除以正样本数量？是为了公平。如果批次里张三有 5 张图，李四只有 2 张图，如果不求平均，张三产生的损失总和会远大于李四，导致模型偏心（专门去学张三的特征）。除以数量后，就变成了平均损失

这里，$P(y_i) = \{p \in 1...B : y_p = y_i\}$ 是批次中 $T_{y_i}$ 的所有正样本的索引集合，$|\cdot|$ 是其基数。通过最小化 $\mathcal{L}_{i2t}$ 和 $\mathcal{L}_{t2i}$ 的损失，梯度通过固定的 $\mathcal{T}(\cdot)$ 反向传播来优化 `[X]`$_1$`[X]`$_2$`[X]`$_3$...`[X]`$_M$，从而充分利用了 $\mathcal{T}(\cdot)$。

$$
\mathcal{L}_{stage1} = \mathcal{L}_{i2t} + \mathcal{L}_{t2i} \quad (5)
$$

> - 第一阶段的总损失$$\mathcal{L}_{stage1} = \mathcal{L}_{i2t} + \mathcal{L}_{t2i}$$第一阶段的总损失，是两个方向损失的相加（图像找文本和文本找图像）

- 为了提高计算效率，在第一训练阶段开始时，我们将整个训练集输入到 $\mathcal{I}(\cdot)$ 中以获取所有的图像特征。对于具有 $N$ 个 ID 的数据集，我们在本阶段结束时保存所有 ID 的 $N$ 个不同的 $T_{y_i}$，为下一阶段的训练做准备。
### 第二阶段训练
**第二训练阶段。** 在这个阶段，只优化 $\mathcal{I}(\cdot)$ 中的参数。为了提升最终性能，我们遵循目标 ReID 的通用强大流程（Luo et al. 2019）。我们采用带有标签平滑（label smoothing）的难样本挖掘三元组损失 $\mathcal{L}_{tri}$ 和 ID 分类损失 $\mathcal{L}_{id}$ 进行优化，计算如下：
$$
\mathcal{L}_{id} = \sum_{k=1}^N -q_k \log(p_k) \quad (6)
$$
> - 这是一个标准的分类损失（Cross Entropy），目的是让图像编码器学出具有区分性的特征，即“看到张三的图，模型得知道他是张三”。 
> - $p_k$： 模型预测当前图片属于类别 $k$ 的概率。
> - $q_k$（标签平滑 Label Smoothing）： 这是 ReID 中的常用技巧。
>   - 通常的标签是“硬”的（比如 $q = [1, 0, 0]$），这会导致模型过度自信，容易过拟合。
>   - 这里用了 $\epsilon$ 进行平滑（比如 $q = [0.9, 0.05, 0.05]$），强迫模型不要死记硬背，而是学习更具泛化性的特征，给其他长得像的 ID 留一点容错空间。

$$
\mathcal{L}_{tri} = \max(d_p - d_n + \alpha, 0) \quad (7)
$$
> - 解决“类内距离”和“类间距离”的问题。
> - $d_p$（正样本距离）： 同一个人（同一 ID）两张不同照片特征之间的距离。
> - $d_n$（负样本距离）： 两个不同人照片特征之间的距离。核心逻辑： 模型希望 $d_n$ 远大于 $d_p$。只要 $d_n$ 比 $d_p$ 大出一个裕度 $\alpha$，损失就是 0。
>   - 把同一个人（正样本）在特征空间里拉近，把不同的人（负样本）踢开。

其中 $q_k = (1 - \epsilon)\delta_{k,y} + \epsilon/N$ 表示目标分布中的值，$p_k$ 表示类别 $k$ 的 ID 预测逻辑值（logits），$d_p$ 和 $d_n$ 分别是正样本对和负样本对的特征距离，$\alpha$ 是 $\mathcal{L}_{tri}$ 的边界裕度（margin）。为了充分利用 CLIP，对于每张图像，我们可以使用在第一阶段获得的文本特征来计算图像到文本的交叉熵损失 $\mathcal{L}_{i2tce}$，如公式 (8) 所示。注意，与 $\mathcal{L}_{id}$ 类似，我们在 $\mathcal{L}_{i2tce}$ 的 $q_k$ 上也使用了标签平滑。

$$
\mathcal{L}_{i2tce}(i) = \sum_{k=1}^N -q_k \log \frac{\exp(s(V_i, T_{y_k}))}{\sum_{y_a=1}^N \exp(s(V_i, T_{y_a}))} \quad (8)
$$

> - 核心概率项（Softmax 结构）
> $$
> \frac{\exp(s(V_i, T_{y_k}))}{\sum_{y_a=1}^N \exp(s(V_i, T_{y_a}))}
> $$
>  - $V_i$： 当前正在训练的第 $i$ 张图片的视觉特征（来自图像编码器）。
>  - $T_{y_k}$： 全数据集中第 $k$ 个 ID 的文本特征锚点。注意，这里的 $k$ 是从 $1$ 到 $N$ 遍历全数据集所有的 ID。
>  - $s(V_i, T_{y_k})$： 图像与文本之间的相似度。
>     - 分母： 是当前图像 $V_i$ 与全数据集所有 ID 的文本描述的相似度总和。
>     - 整个分式： 代表了图像 $V_i$ 被正确分类到第 $k$ 个文本描述下的预测概率。
> - B. 标签平滑项（Label Smoothing）
>  - $q_k$： 这是目标分布（真值）。
>     - 如果不用标签平滑，对应的 ID 位置 $q_k=1$，其余为 $0$。
>     - 使用了标签平滑后，真值 ID 的 $q_k$ 会稍微减小（比如 $0.9$），而给其他 ID 分配一个极小的概率（比如 $0.1/N$）。
>  - 作用： 防止图像编码器过于死板地去匹配某一个文本，增强了模型处理模糊图像（如遮挡、低分辨率）时的鲁棒性。
> - C. 外层的求和与负对数
>  - $-\log$： 经典的交叉熵。预测概率越高，损失越小。
>  - $\sum_{k=1}^N$： 遍历全数据集所有的 ID 类别。

最终，我们第二训练阶段使用的总损失总结如下：
$$
\mathcal{L}_{stage2} = \mathcal{L}_{id} + \mathcal{L}_{tri} + \mathcal{L}_{i2tce} \quad (9)
$$


所提出的 CLIP-ReID 的完整训练过程（包括第一和第二阶段）总结在算法 1 中。我们使用可学习的提示来挖掘并存储预训练图像和文本编码器的隐藏状态，使 CLIP 能够保留自身的优势。在第二阶段，这些提示可以正则化图像编码器，从而提高其泛化能力。

### SIE（侧信息嵌入）与 OLP（重叠分块）
为了使模型能够感知摄像头或视角信息，我们采用了 侧信息嵌入（SIE） 来引入相关背景信息。与之前的 TransReID 不同，我们仅将摄像头信息添加到 `[CLS]` 标记（token）中，而不是所有的标记上，以避免干扰图像的细节特征。重叠分块（OLP） 可以在增加计算资源的前提下进一步增强模型性能，其实现方式非常简单，只需更改 Token 嵌入层中的步长（stride）即可。
> - SIE：聪明的侧信息注入
>   - 做法： 告诉模型“这是 3 号摄像头拍的”。
>   - 创新点： 只把这个信息告诉负责全局的 [CLS]（班长），而不干扰负责局部细节的 Patch Tokens（组员）。
>   - 好处： 既让模型知道环境变化，又保住了最纯净的图像细节（比如衣服纹理）。
> - OLP：更细腻的图像切片
>   - 做法： 传统的 Vision Transformer 切图是“切豆腐”，块与块之间不重叠。OLP 通过减小步长，让相邻的图块之间有重叠。
>   - 好处： 这种“有重叠的视野”能让模型捕捉到跨越边界的细微特征，让视觉提取更加连续、细腻。
