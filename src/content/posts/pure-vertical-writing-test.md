# 纯直排页面

这篇文章用于测试整篇文章都采用直排渲染时的阅读节奏。和局部直排块不同，这里从标题、段落到小节说明都会进入竖排环境，适合放置古典文本札记、文语文摘抄，或以原文为中心的读书记录。

## 文语段落

```ruby
色(いろ)は匂(にほ)へど、散りぬるを。我が世たれぞ、常ならむ。有為の奥山(おくやま)、今日越えて、浅き夢見じ、酔ひもせず。

普通\(括号)はそのまま出る。
```

直排页面里仍然可以混合汉字、假名和标点。这里的段落稍长一些，用来观察行高、列距和页面滚动方向。若文章以后需要放古汉语、日语文语或训读材料，可以把正文直接写成普通 Markdown，只在需要精确标注返点和送假名的地方插入训点块。

## 训点材料

```kanbun
故[レ]人不[二]獨リ親シ[一]其親ヲ、不[二]獨リ子トス[一]其子ヲ。
```

这里测试返点、送假名和正文列距是否能共存。返点应嵌入汉字基字与下一个汉字之间的左侧空隙，送假名则贴近对应汉字并保持较小字号。

## 春望训点

下面放一首稍长一点的古诗作为测试材料。这里不追求训读的严格校勘，只用于观察句子换行、返点位置、送假名密度，以及长篇训点材料在纯直排页面中的横向展开效果。每一联都单独写成一个段落，避免五言半句被拆成两行。

```kanbun
國(くに)破レテ‘山河’(さんが)在リ、城春ニシテ草木深シ。

感[二]時ニ[一]花濺グ[レ]淚ヲ、恨[二]別レヲ[一]鳥驚カス[レ]心ヲ。

烽火連ナル[二]三月ニ[一]、家書抵ル[二]萬金ニ[一]。

白頭搔ケバ更ニ短ク、渾テ欲ス[レ]不[レ]勝ヘ[レ]簪ニ。
```

这类内容会比普通段落更占横向空间，所以页面应当保持向左展开的余地。手机上则重点确认两件事：一是行长不要超出屏幕高度太多，二是横向滚动时不要被外层容器截断。

## 札记

直排文章不一定只放原文，也可以接续简短评注。比如这里可以写文本异同、词义说明、训读顺序，或把几个版本的差异整理成连续笔记。页面右侧的液态玻璃索引仍然保留，但文章主体不再使用右栏目录，避免干扰直排阅读。

## 收束

若正文越来越长，直排页面会以横向滚动承载列数。这个测试页故意写得稍长一些，方便检查滚动、标题、普通段落和训点块在同一页面中的表现。
